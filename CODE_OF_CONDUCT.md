# Contributor Covenant Code of Conduct

We pledge to make participation in the xping community a
harassment-free experience for everyone. Be respectful, accept
constructive criticism gracefully, and focus on what's best for the
community.

Unacceptable: harassment, personal attacks, publishing others'
private information without permission.

Report violations to **iorganamis@gmail.com**.

Adapted from [Contributor Covenant 2.1](https://www.contributor-covenant.org/).
