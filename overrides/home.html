Your network,
rendered — not just measured.

xping turns ping, traceroute, DNS, TLS, HTTP and Wi-Fi checks into live, colour-coded terminal output — and tells you in plain words why the internet is not working. No root needed, one small dependency, every result also as JSON, CSV or Markdown.

What it does

One tool for when the network acts up

Thirty-odd commands share one rendering language and one set of exit codes — the same colours mean the same thing whether you watch one ping or monitor a whole office.

Troubleshoot

Get a verdict

  • doctor — why the internet is not working, step by step, in plain words
  • health — a 0–100 score from loss, latency and jitter
  • net — interfaces, gateway, DNS, public IP, and whether a VPN carries your trafficNEW
  • wifi — signal, noise, SNR, channel crowding and what to do
Watch

See it over time

  • monitor — a live dashboard of all your checks, or a background serviceNEW
  • --watch / --until-up with desktop and webhook alerts
  • --fail-after — one blip is not an outage
  • history and report — trends and an HTML uptime page
Inspect

Ask a host about itself

  • http — status, redirects and a DNS → TLS → TTFB waterfall
  • tls, smtp — certificates, expiry, STARTTLS
  • dnscheck — SPF, DMARC, DKIM, DNSSEC, MX, NS
  • lookup, propagation, blocklist, whois
Trace & scan

Follow the path

  • trace, mtr — per hop, with AS names, also over TCP
  • tcp, udp, mtu, ntp, speedtest
  • portscan, sweep, ipscan across ranges
  • check — many checks from one file, one exit code

Get it running

Pick your platform

Pure Python plus certifi for TLS — no compiled extensions. Every channel ships the man page; Homebrew and the PPA also set up tab completion.

brew install mehaskari/tap/xping

Man page and completion for bash, zsh and fish included. Upgrade with brew upgrade xping; the tap follows PyPI releases on its own.

sudo add-apt-repository ppa:mehdiaskari/xping sudo apt update sudo apt install xping

Built for Ubuntu 24.04 LTS (noble) and distributions based on it: Linux Mint 22, Pop!_OS 24.04. Tab completion for bash, zsh and fish is set up for you.

pipx install xping

Any platform with Python 3.10 or newer (pip install xping works too). Then set up tab completion once: xping completion --install.

sudo snap install xping

Newest builds from main: sudo snap install xping --edge.

pipx install xping xping doctor xping deps

TCP, HTTP, TLS, DNS, scans and net work out of the box; ping and traceroute use Windows' own ping / tracert. xping deps shows what is available.

  1. Clone the repository — git clone https://github.com/mehaskari/xping
  2. Enter the directory — cd xping
  3. Install — pip install .
  4. Tab completion — xping completion --install

No root, no setcap

ping, trace and mtr use the unprivileged ICMP sockets of macOS and Linux, so they run as you. Run as root and xping uses raw sockets; with neither, the system ping and traceroute.

First steps

xping doctor — is the internet working?
xping 1.1.1.1 — ping, then suggestions
xping check --init — your own checks
